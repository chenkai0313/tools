    📖 密码生成器使用说明

    工具简介

    密码生成器是一个在线随机密码生成工具，可以根据你的需求生成高强度、难以破解的随机密码。支持自定义字符类型组合、密码长度，并可以排除容易混淆的相似字符（如 0 和 O、1 和 I 等）。

    功能说明

    • 字符类型选择：大写字母、小写字母、数字、特殊符号自由组合
    • 长度调整：支持 1~64 位密码长度
    • 排除相似字符：避免混淆 0/O、1/I/l 等
    • 密码强度指示：实时显示密码强度等级

    使用方法

    1. 勾选需要的字符类型（大写、小写、数字、符号）
    2. 拖动滑块调整密码长度
    3. 开启"排除相似字符"避免混淆
    4. 点击生成按钮，复制你满意的密码

    示例

    全部字符类型，16 位长度： kG7#mP2$xQ9&vR5@ 大小写+数字，排除相似，12 位： Ab3Xm8Kp2Rw7

    应用场景

    • 注册网站时生成高强度账户密码
    • 为服务器生成 SSH 密钥或数据库密码
    • 生成 Wi-Fi 密码、应用密钥等
    • 定期更换密码时生成新密码
