    加解密

    AES/DES 对称加密 和 RSA 非对称加密

    📖 加解密工具使用说明

    工具简介

    加解密工具提供对称加密（AES、DES）和非对称加密（RSA）两种加密方式。所有加解密操作在浏览器端完成，数据不会上传到任何服务器，保障你的数据安全。支持密钥生成、加密解密以及数字签名验证。

    功能说明

    • AES 对称加密：使用相同的密钥加密和解密，支持密钥自动生成
    • DES 对称加密：经典的对称加密算法
    • RSA 非对称加密：公钥加密、私钥解密，支持密钥对生成
    • RSA 签名验证：私钥签名、公钥验签，确保数据完整性和来源可信
    • 浏览器端处理：所有计算在本机完成，数据不上传

    使用方法

    1. 选择加密方式（AES、DES 或 RSA）
    2. 对称加密：输入或生成密钥，选择加密/解密模式，输入文本
    3. RSA 加密：生成密钥对，使用公钥加密，私钥解密
    4. 查看结果，双击复制密文或明文

    示例

    AES 加密： 明文：Hello World 密钥：MySecretKey123 密文：U2FsdGVkX1/... RSA： 生成 2048 位密钥对 → 公钥加密 → 私钥解密 或：私钥签名 → 公钥验证

    应用场景

    • 本地加密敏感配置文件，防止明文泄露
    • API 通信中使用 RSA 公钥加密传输密钥
    • 使用 RSA 签名验证软件包或消息的完整性
    • 学习对称加密和非对称加密的原理和区别
